# 平台租客简易模式开关

入口：系统管理员登录平台 → 租客全景 → 查询并选择租客 → 查看 → 概览与当前订购 → 简易模式。

本地地址：http://127.0.0.1:3030/admin-wms/platform/tenants 。切换只针对当前抽屉明确显示的租客编码，不修改生产接入渠道。

## 接口

- GET /api/v1/platform-tenants/simple-mode/query，query参数tenant_id。
- POST /api/v1/platform-tenants/simple-mode/update，multipart/form-data，仅tenant_id、enabled（0/1）、expected_revision（最新已查询版本）。

复用已有平台管理员认证，不新增后端路径或权限SQL。每次打开租客详情重新查询；失败时开关不可操作，支持刷新重试。

## 交互

- 展示后端真实状态，点击开关后显示租客名称及编码的确认框；取消不请求修改。
- 保存期间禁止重复点击；成功后以后端返回的状态和revision为准，失败不乐观翻转。
- 无条码余额或未结束简易任务阻止关闭时，展示中文原因、产品/任务ID、存放对象及精确数量。
- 并发版本冲突后仅刷新状态，提示用户重新核对，不自动重试写入。
- 租客切换或组件销毁后丢弃旧响应；旧租客确认窗口返回后不再提交旧目标。
- HTTP公共层保留FastAPI detail错误对象，使关闭阻断和版本冲突详情不会丢失。

## 验证

平台管理端56项测试通过，Vue类型检查通过。浏览器加载完整平台页面，在独立上下文拦截模拟平台响应，验证抽屉入口、取消不发送、开启成功、服务端拒绝关闭及阻断明细、刷新后关闭成功，页面运行时错误0。

未使用真实平台管理员凭证切换实际租客；本轮浏览器回归未修改真实租客开关、库存或权限。
