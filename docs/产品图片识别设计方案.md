# 新增产品页「图片识别」功能设计与实现方案

> 版本：v1.1（2026-08-07；已确认：预览窗口交互、识别图独立、仅登录可用）
> 范围：`wms-vue3`（前端）+ `nuomi_wms`（后端）；模型能力：豆包（火山方舟）多模态视觉理解
> 状态：方案待评审

---

## 一、需求背景与目标

「新增产品资料」页面字段多（3 个 Tab、20+ 字段），手工录入繁琐且易错。用户希望在该页面右上角（重置、保存按钮左侧）增加一个「图片识别」入口：上传一张产品图片（包装照片 / 产品标签 / 价签），由豆包多模态大模型识别并提取产品字段，用户确认后自动填入表单，减少录入成本。

### 目标

1. 从 1 张产品图片中提取产品字段（名称、货号、规格、产地、颜色、重量等）。
2. 识别结果以「确认弹窗」形式展示（含置信度），用户勾选后批量回填表单。
3. 仅作用于「新增产品资料」场景，不影响其他新增页；编辑态、只读态不提供（本期）。
4. 复用现有安全架构：服务端持有密钥、JWT 鉴权、不落盘图片、失败不阻塞表单。

### 2.3 模型能力（火山方舟图片理解）

- 接口：Chat API（OpenAI 兼容）`POST /api/v3/chat/completions`，与现有代理同一端点。
- 图片传入：`messages[].content` 为数组，`{"type":"image_url","image_url":{"url":"data:image/png;base64,<b64>"}}`。
- 约束：单张图片 base64 直传 **< 10MB**、请求体 **< 64MB**；视觉模型示例 `doubao-seed-2-1-pro-260628`（Seed2.1 旗舰，图片理解更强）、`doubao-seed-2-0-lite-260428`（Seed2.0 全模态，PageAgent 已开通）。**本方案实际选用 `doubao-seed-2-0-lite-260428`**（复用现有开通，零新增；识别精度满足产品字段提取场景）。
- 结构化输出：支持 `response_format: {"type":"json_object"}`（JSON 模式），适合让模型返回字段 JSON。

## 三、需求规格（细化）

### 3.1 功能边界

| 维度 | 规则 |
| --- | --- |
| 入口 | 仅 `config.type === 'productInfo'` 且新增态（`!isEdit && !isReadonly`）显示；其他场景不渲染 |
| 图片 | 每次 1 张；格式 png / jpg / jpeg / webp；≤ 10MB（与产品图片上传上限一致）；前端本地校验 |
| 触发 | 选择图片后**打开预览窗口**（展示所选图片 + 图片格式/大小信息）；在预览窗口内点击「开始识别」才发起识别；识别期间按钮 loading 防重复提交，可在预览窗口「重新选图」 |
| 结果确认 | 弹窗列出各字段：字段名 / 识别值 / 置信度（高·中·低）/ 来源；默认勾选高置信；中低置信不勾选；用户可改勾选 |
| 识别图去向 | 仅内存使用（base64 直传模型），**不保存为产品图片、不进入 `images`/`attachments`**，与产品图片上传完全独立（默认独立） |
| 应用 | 点「应用到表单」：勾选字段回填；已手动填写的字段**不覆盖**（跳过并提示）；字典未匹配字段提示手动选择 |
| 取消 | 关闭弹窗不产生任何表单变更 |
| 编辑/只读态 | 本期不提供（避免覆盖已有产品数据的复杂语义） |

### 3.2 识别字段与映射分级

| 级别 | 字段 | 处理 |
| --- | --- | --- |
| A 自由文本（直接回填） | `product_name`、`item_no`、`specification`、`origin_place`、`color`、`remark` | 高置信直接应用；中置信默认不勾选；空值不产生条目 |
| B 数值（校验后回填） | `unit_weight`、`package_qty`、`factory_price`、`weight_tolerance`、`convert_ratio`、`stock_warning_qty`、`production_cycle_days` | 模型返回字符串，前端 `Number()` 校验；非法/含非数字字符丢弃并给出原因（如 `factory_price` 必须 >0、`gross_profit_ctrl_rate` 0~1 属于 C 级配置项不识别） |
| C 字典映射（名称→ID） | `category_id`（产品类别树）、`unit_id`（主计量单位）、`assist_unit_id`（辅助单位） | 模型返回**名称**，系统在缓存字典中精确/包含匹配取 ID；匹配不到则该条标记「未匹配」，提示用户手动选择 |
| D 不识别（保留默认） | `product_type`、`product_status`、`is_weighing`、`is_combined`、`fifo_flag`、`min_sale_price`（计算值）、`sale_prices`、`product_suppliers`、`images`、`attachments` | 不在识别范围；模型指令中明确禁止输出 |

**覆盖保护**：任何字段若用户已填写非空值，识别结果一律不覆盖，应用时跳过并提示「字段 X 已填写，未覆盖」。

### 3.3 非功能要求

| 类别 | 要求 |
| --- | --- |
| 权限 | **仅登录可用**：识别接口走 JWT 鉴权（`get_current_operator`），登录用户即可调用；不引入按钮级权限（免 SysApiFunction 配置依赖），后续如需收紧再升级 |
| 安全 | 图片仅内存处理，**不落盘、不入库、不进日志**；API Key 仅服务端环境变量；识别请求受全局限流约束；前端不接触任何模型密钥 |
| 性能 | 目标识别耗时 < 10s；请求超时 60s（模型响应）；前端 loading 防重复提交 |
| 可用性 | 模型不可用 / 超时 / 解析失败均返回友好错误，表单状态不受影响；识别失败可重试 |
| 审计 | 识别接口日志仅记录：操作人、时间、图片大小/格式、模型、返回字段 key 清单、错误摘要；**不含图片内容与识别文本**（可选增强） |

### 3.4 验收标准（AC）

1. 「图片识别」按钮仅出现在新增产品页右上角，编辑态/只读态/其他新增页不显示。
2. 上传一张含「产品名称 + 货号 + 规格型号」的标签图，先打开预览窗口；点击「开始识别」后结果弹窗展示 3 个识别字段且置信度标注正确；勾选应用后表单 3 个字段正确回填。
3. 用户已手填的产品名称不被识别结果覆盖（提示跳过）。
4. 类别/单位无法匹配时，该条目显示「未匹配」提示，其余字段正常应用。
5. 上传 >10MB 或非白名单格式图片，前端直接报错，不发请求。
6. 未登录调用接口返回 401；识别接口不依赖按钮级权限，登录用户均可使用。
7. 模型服务不可用时返回 502/504 类友好错误，表单可继续使用。

## 四、实现方案

### 4.1 总体数据流

```
┌─ 前端 AddTemplate.vue（productInfo 场景）─────────────────┐
│  [图片识别]按钮 → 选图(≤10MB,白名单) → 预览窗口 → 点击      │
│      [开始识别] → POST /api/v1/tenant-products/recognize    │
│      ▼                                                    │
│  识别结果确认弹窗（字段+置信度+勾选）→ 应用到表单           │
│      · A/B 级: formData[key]=value（非空不覆盖）           │
│      · C 级: 字典匹配 → 命中填 ID / 未命中提示              │
└───────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─ 后端 nuomi_wms ──────────────────────────────────────────┐
│  POST /api/v1/tenant-products/recognize                   │
│  ① JWT 鉴权（依赖 page_agent_proxy 同款）                 │
│  ② 校验图片：格式/大小（≤10MB）→ base64                   │
│  ③ 构造 prompt：产品字段清单+枚举+字典名称快照+JSON Schema │
│  ④ 调火山方舟 Chat API（视觉模型，response_format=json）  │
│     httpx 单例 + 指数退避重试（复用代理模式）              │
│  ⑤ 解析/校验 JSON → 归一化字段 → 返回                    │
│     { fields: { key: {value, confidence, source} } }      │
└───────────────────────────────────────────────────────────┘
```

### 4.2 后端实现

#### 4.2.1 新增配置（`app/core/config.py` + `.env`）

独立于 PageAgent 的视觉模型配置，避免影响现有代理：

```dotenv
# 产品图片识别（火山方舟视觉模型，OpenAI 兼容）
PRODUCT_VISION_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
PRODUCT_VISION_MODEL=doubao-seed-2-0-lite-260428   # 复用 PageAgent 同款全模态模型
PRODUCT_VISION_API_KEY=xxx
PRODUCT_VISION_TIMEOUT_SECONDS=60
PRODUCT_VISION_MAX_RETRIES=2
PRODUCT_VISION_MAX_IMAGE_BYTES=10485760            # 10MB
```

> 复用点：`BASE_URL` 与 PageAgent 相同可共用，但模型与 Key 独立配置更安全（视觉模型消耗高，可单独控流/审计）。

#### 4.2.2 新增接口（`tenant_product_management.py`，前缀 `/api/v1/tenant-products/`）

```
POST /api/v1/tenant-products/recognize
Content-Type: multipart/form-data
Body: image: File（必填，1 张）, scene: str = 'productInfo'（预留扩展）
响应: ApiResponse{success, message, data: {
  request_id: str,
  model: str,
  fields: {
    product_name:  {value: str|null, confidence: 'high'|'medium'|'low', source: 'image'},
    item_no:       {...},
    specification: {...},
    origin_place:  {...},
    color:         {...},
    unit_weight:   {...},
    package_qty:   {...},
    factory_price: {...},
    category_name: {...},   // C 级：返回名称，由前端匹配 ID
    unit_name:     {...},
    ...
  },
  warnings: str[]
}}
```

实现要点：

1. **鉴权**：`Depends(get_current_operator)`，**仅登录可用**（本期决策）；不挂按钮级权限，免 SysApiFunction 配置。
2. **图片校验**：`await image.read()`，检查 `content_type` 白名单（image/png、image/jpeg、image/webp）、大小 ≤10MB、非空；超限返回 400。
3. **prompt 构造**（核心质量杠杆，参考 PageAgent 系统提示词经验）：
   - 系统提示：角色=「WMS 产品资料录入助手」，任务=从图片提取产品字段，**只输出 JSON**（`response_format: json_object`），列出 A/B/C 级字段清单与说明（如 `factory_price` 需为大于 0 的数字字符串、`unit_weight` 为数值字符串），**禁止**输出 D 级字段、禁止编造图片中不存在的值（无则 `null`）。
   - 附字典名称快照：类别树一级/常用节点名称列表、计量单位名称列表（服务端可查，或由前端随请求带上；**推荐服务端查**，减少前端负担与请求体）。
   - 用户消息：`[{type:'text',text:'请识别图中产品信息'},{type:'image_url',image_url:{url:'data:image/<ext>;base64,<b64>'}}]`。
4. **上游调用**：复制 `page_agent_proxy.py` 的 httpx 单例客户端 + `_post_upstream_with_retry` 模式；强制 `model=settings.product_vision_model`、`stream=False`；`response_format={"type":"json_object"}`。
5. **响应解析**：`json.loads(choices[0].message.content)`；字段白名单过滤；confidence 归一化（模型输出或默认 medium）；非法数值置 null；包裹 `warnings`（如「未识别到价格信息」）。
6. **错误映射**：超时→504、连接失败→502、模型返回非 JSON→503（带可读 message）、上游 4xx→透传摘要。
7. **日志**：仅 `request_id / operator_id / image 大小 / model / fields keys / latency / error`，不含图片与文本。

#### 4.2.3 建议新增文件

- `app/services/product_vision_service.py`：prompt 构造、字典快照查询、上游调用、响应归一化（保持 endpoint 轻薄，与 `page_agent_proxy` 拆代理/业务逻辑的思路一致）。

### 4.3 前端实现

#### 4.3.1 场景配置扩展（推荐做法，非硬编码）

`formConfigs.ts` `SceneConfig` 增加可选字段：

```ts
/** 场景级扩展操作：当前仅支持图片识别回填 */
extraActions?: Array<{ key: 'image-recognize'; enabled?: (ctx) => boolean }>
```

`productInfo` 场景声明：

```ts
extraActions: [{ key: 'image-recognize' }]
```

`AddTemplate.vue` 的 `.header-actions`（`:10-14`）按配置渲染：

```html
<template v-if="!isReadonly">
  <ProductRecognizeAction
    v-if="hasAction('image-recognize') && !isEdit"
    :form-data="formData"
    :field-options="fieldOptions"
    @applied="onRecognizeApplied"
  />
  <el-button @click="handleReset">重置</el-button>
  <el-button type="primary" ...>保存</el-button>
</template>
```

> 优点：入口随场景配置显隐，不会误出现在其余几十类新增页；后续其他场景想用可一键开启。

#### 4.3.2 新组件 `ProductRecognizeAction.vue`（`src/views/product/`）

职责：按钮 + 选图 + 预览 + 识别结果确认弹窗 + 回填。

- **按钮**：`图片识别`（图标 `Picture` / `MagicStick`），loading 态禁用。
- **选图**：隐藏的 `<input type="file" accept="image/png,image/jpeg,image/webp">`，校验 ≤10MB 与格式；选中后**打开预览窗口**（`el-dialog`：内含 `<el-image>` 预览 + 图片格式/大小信息 + 「开始识别」主按钮 + 「重新选图」）。
- **识别**：预览窗口内点「开始识别」→ 按钮 loading → 调 `recognizeProductImage(file)` → 关闭预览窗口、打开结果确认弹窗。
- **结果弹窗**：`el-dialog` 内表格（字段名 / 识别值 / 置信度 tag / 勾选），高置信默认勾选；底部「应用到表单 / 取消」。
- **回填逻辑**：
  - A 级：`formData[key] = value`（若 `formData[key]` 非空 → 跳过并收集提示）。
  - B 级：`Number(value)` 校验通过才写；失败行标记原因不写。
  - C 级：在 `fieldOptions` / `treeCache:productCategory` / `optionsCache:productUnit` 中匹配（精确 → 包含，忽略大小写）；命中写 ID，未命中标记「未匹配」并给出候选名称供手动选择。
  - 应用完成 `ElMessage.success('已应用 N 个字段，跳过 M 个')`，未匹配项引导用户手动选择。
- **加载字典**：回填前按需调用现有 `loadOptions` 逻辑补齐 `fieldOptions`（复用 `AddTemplate` 的缓存机制：`treeCache:productCategory`、`optionsCache:productUnit`）。

#### 4.3.3 API 封装（`src/api/modules/product.ts`）

```ts
/** 产品图片识别（接口：POST /api/v1/tenant-products/recognize） */
export function recognizeProductImage(file: File): Promise<ApiResponse<ProductRecognizeResult>> {
  const fd = new FormData()
  fd.append('image', file)
  fd.append('scene', 'productInfo')
  return post('/api/v1/tenant-products/recognize', fd)
}
```

> `post` 对 FormData 自动设置 multipart 头；axios 拦截器自动带 token、统一错误提示。

#### 4.3.4 边界处理

- 识别进行中：按钮 loading + 弹窗不可重复打开；若用户已填表单，不影响。
- 识别失败：`ElMessage.error('识别失败：xxx')`，可重试；不污染表单。
- 组件卸载/路由离开：中止未完成请求（`AbortController`，可选增强）。
