# 退货明细表格 UI 优化需求

## 一、任务目标

请优化当前退货管理页面中的「退货明细」模块，仅进行前端 UI/UX
层面的优化，不修改后端接口、不改变数据结构、不改变业务逻辑。

目标：

将当前传统 ERP 式表格，优化为更加现代化、专业化的 WMS 企业管理系统界面。

设计方向参考：

-   SAP Fiori 企业应用设计理念
-   飞书/钉钉管理后台的信息密度设计
-   现代 SaaS 管理系统 UI 风格

核心原则：

1.  信息层级清晰
2.  减少无效输入框视觉噪音
3.  突出商品信息和退货数量操作
4.  提升仓库人员操作效率
5.  保持深色主题适配

## 二、整体布局优化

当前问题：

现有表格所有字段权重一致：

序号、销售单号、产品编码、产品名称、单位、可退余量、退货数量、单价、状态、备注、操作。

导致：

-   页面横向空间占用过大
-   核心字段不突出
-   产品信息阅读效率低

优化要求：

重新调整字段视觉优先级。

### 一级信息（重点展示）

商品信息：

包含：

-   产品编码
-   产品名称

展示形式：

不要使用输入框。

改为信息展示卡片：

    G000003

    诺米家居-双色温接收器

其中：

产品编码：

-   小字号
-   弱化颜色

产品名称：

-   主标题
-   高亮显示

### 二级信息（操作区域）

重点突出：

#### 可退数量

展示：

    可退：
    5 件

#### 退货数量

改为数字步进输入：

    [-] 1 [+]

要求：

-   支持快速调整数量
-   不允许超过可退数量
-   保持输入区域明显

### 三级信息

以下字段降低视觉权重：

-   单位
-   退货单价
-   产品状态
-   备注

不要占用大量横向空间。

## 三、表格结构优化

如果继续保持 Table 形式：

调整为：

  序号   商品信息   可退数量   退货数量   状态   单价   备注   操作
  ------ ---------- ---------- ---------- ------ ------ ------ ------

禁止：

产品编码和产品名称独立占用两个大列。

## 四、输入框优化

当前问题：

大量 input 导致页面像表单录入页面。

优化规则：

### 非编辑字段

以下字段改为纯展示：

-   产品编码
-   产品名称
-   单位
-   可退数量

不要显示输入框。

### 编辑字段

仅保留：

-   退货数量
-   产品状态
-   备注

使用统一输入组件。

## 五、产品状态优化

当前：

select 下拉框。

优化：

使用状态 Tag / Badge 风格。

示例：

    ● 完好

状态颜色：

-   完好：绿色
-   包装破损：黄色
-   已使用：红色

要求：

状态视觉更加直观。

## 六、备注字段优化

当前备注输入框过宽。

优化：

默认缩小。

建议：

宽度：

150-200px。

或者：

改为点击编辑备注。

展示：

    暂无备注

点击后展开输入。

## 七、删除操作优化

当前：

单独红色垃圾桶。

优化：

-   hover 显示
-   使用 Tooltip
-   增加确认提示

删除图标保持弱化，鼠标悬浮时显示危险色。

## 八、增加明细统计区域

在退货明细标题区域增加统计信息：

    退货商品数量：3

    退货总数量：12

    退货金额：¥3560

采用轻量 Summary Card。

不要影响主体操作。

## 九、深色主题要求

页面必须适配当前深色主题。

要求：

-   避免大面积纯黑
-   避免高饱和颜色
-   输入框使用低亮度背景
-   边框弱化
-   状态颜色仅用于强调

整体效果：

专业、克制、企业级。

## 十、交互体验要求

优化后：

仓库人员打开退货单后，第一眼看到：

1.  退什么商品
2.  能退多少
3.  当前退多少

操作流程：

查看商品 → 修改数量 → 选择状态 → 填备注 → 保存

减少无意义点击。

## 十一、代码要求

1.  保留现有组件结构
2.  不修改接口字段
3.  不修改业务逻辑
4.  提取重复 UI 为组件
5.  保证组件高内聚低耦合

建议拆分：

    ReturnDetailTable.vue

    ProductInfoCell.vue
    QuantityStepper.vue
    StatusTag.vue
    RemarkEditor.vue

保持后续：

采购明细、销售明细、出库明细、入库明细可以复用。

## 最终效果

将当前传统 ERP 数据表转换为现代化 WMS 单据明细组件。

重点突出：

-   商品信息
-   数量操作
-   状态管理

整体视觉：

简洁、专业、高效，适合仓库业务人员长期使用。
