## 三、待落地（按优先级）

### P0（体验/收益最大）

1. ⚠️ **标签与过滤检索（P2）— v1 已落地（2026-11-24）**
   - ✅ 标签表 `data_workspace_tag` / `data_workspace_document_tag`（迁移 002）；维度轴固定 domain/category/custom，取值由用户创建，企业内共享；
   - ✅ `/tags` 创建/列表；`/documents/{id}/tags` 读取/替换；`/documents/{id}/tag-suggestions` 按用户标签名与 keywords 动态匹配（无固定分类规则）；
   - ✅ `/search` 支持 `tag_ids`（文档级过滤，先筛文档再向量检索）；标签变更不重算向量、复用同一处理任务；
   - ✅ 前端：入库步骤动态标签选择/新建/建议、知识库列表展示标签、检索面板标签筛选；
   - ⏳ 剩余：字典管理页（改名/合并同义词/停用）、历史 `category` 文本迁移映射、知识库默认标签、批量归类界面、审计日志；
   - ⏳ 第二期：表格行级属性（品牌/型号/类目）过滤 + 混合检索。

2. ⏳ **图片处理增强**
   - 扫描页补充描述提示词加强：页面含照片/示意图就必须描述（本次实测 2/8 返回 `[无补充内容]`）；
   - 图片类型打标：产品实拍 / 安装示意 / 尺寸图 / 场景图 / 爆炸图 / 图标（规则 + 模型，写入 `origin.image_tags`）；
   - 图片描述中的尺寸/型号与同页 OCR 文本交叉校验，冲突标注“不确定”而非直接入库。

3. ⏳ **大文件服务端游标预览**：当前仍读取完整解析 JSON 后切片；改为分页读取（块索引文件或按行游标），表格分页展示（当前前 100 行）。

4. ⏳ **用户容量配额（DP01/DP09 剩余）**：配额字段与接口、在途上传预留、超限提示；`/capabilities` 返回配额与已用容量。

### P1（产品闭环）

5. ⏳ **RAG 问答入口（P3）**：`POST /chat`（检索 k=5 → 上下文 ≤1500 tokens → LLM 流式回答），返回引用 `document/page/section/行号`；前端知识库「问答」页签 + 引用卡片跳转预览。
6. ⏳ **知识库管理剩余**：重命名、描述；成员/共享（需角色模型）；删除的级联语义（当前仅解除资料关联）。
7. ⏳ **检索质量**：混合检索（BM25 + 向量 RRF）、rerank、top-k/阈值调参；建立“问题→期望命中”评测集。
8. ⏳ **文档重处理**：选项变更只重算受影响步骤（当前整份重新 process）；同文件多知识库归属。
9. ⏳ **知识库统计增强**：分块数、向量数、最近检索、存储占用；导出知识库 JSONL。

### P2（规模化与运维）

## 四、待讨论（产品/口径决策）

| 议题 | 需要确认的点 |
| --- | --- |
| 标签治理 | 管理员维护字典还是用户自由填写？是否要层级/同义词/版本迁移？ |
| 共享与成员 | 知识库是个人库还是组织库？角色（owner/editor/viewer）与共享范围？ |
| RAG 口径 | 是否提供问答？只答已入库资料还是可联网？引用格式（页码/章节/条款）？ |
| 图片能力 | 是否做以图搜图（复用产品库 visual_index）？外部图片链接是否允许？OCR 成本上限？ |
| 配额策略 | 按用户/公司/存储量？7 天回收期是否符合业务预期？ |
| 多语言 | 中英混排检索是否需要专门处理（分词/同义词/翻译检索）？ |
| 类型覆盖 | 是否需要“合同/制度”之外的更多类型（如报价单、检验报告）专用切片？ |
