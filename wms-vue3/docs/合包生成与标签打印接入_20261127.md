# 合包生成与标签打印接入

## 入口和操作

仓库管理 → 合包管理 → 直接在主表勾选记录 → 生成合包条码。取消单独产品选择窗口，不再二次勾选。每条选中记录作为独立任务，即使同一产品多条也不静默去重；单包数量默认沿用原记录，生成件数默认1，提交前可逐项调整数量、件数及可选长度。每行“打印”在生成窗口关闭动画结束后打开共用标签打印窗口。

原列表单行/勾选补打入口保留；多个已选条码仍沿用原打印任务队列，样式在打印任务页出纸时设置。新生成结果可逐条进入直接预览/打印。关闭打印窗口或打印失败均不会再次生成记录，可从合包列表找到已有条码再打印。

## 两个PDA接口

| 功能 | 接口 | 字段 |
| --- | --- | --- |
| 生成 | POST /api/v1/tenant-wms/merge-packages/generate-from-product | FormData：product_id、merge_qty（正数字符串，最多4位小数）、package_count（正整数字符串）、可选merge_length |
| 打印/预览 | POST /api/v1/tenant-wms/merge-packages/print | 复用scannerPrint.ts与PrintLabelDialog：merge_package_id、printer_model_code、label_spec_id、print_mode、print_mode_hardware、label_type、print_qty、可选density、info_switch |

服务地址沿用VITE_SCANNER_API_BASE_URL；不发到主工程。权限沿用PDA既有perm_scanner_merge_all聚合权限，网站不新建权限、不自动给租户授权，服务器检查仍为最终依据。

生成只创建UNOPERATED、source_type=PRINT的记录，不扣库存、不自动入库、不设置打印样式。单包数量×生成件数用于前端精确合计，不混用print_qty（同一个已有条码重复打印几份）。

指定长度时按数字+显式单位发送，例如1500.500001mm或1.5m，支持m/dm/cm/mm；未指定时省略merge_length。显式单位由PDA精确换算，不擅自依赖不完整的辅助单位资料。

返回使用new_merge_packages[]（merge_package_id、barcode_code、merge_qty、merge_length_text等）显示生成结果。print_hint仅作提示，实际打印使用固定的已接入端点，不执行服务端返回的任意URL。

## 每次打印版式

- print_mode=PREVIEW/PRINT分别表示预览/打印。
- info_switch=true为完整标签；false为简易标签（条码+完整编号）。明确传递false，不能在序列化时当空值删除。
- 复用现有弹窗本地选择偏好，不修改PDA合包设置；无后端“以后全都简易”的新设置接口。
- 合包版式切换清空旧预览；预览/打印执行时禁用版式开关，防止将旧版式预览误认作新请求结果。遵循wms-pdf-export技能的参数快照/预览竞态约定，未改变单据PDF导出规则。

## 重复生成保护

生成接口没有request_id幂等协议。前端将各项参数先固定为请求快照，然后逐项串行发送：前一个请求结束后等待300ms再发下一项，首项不等待、末项后不额外等待，不使用Promise.all并发启动。

提交期间禁止重复点击、编辑和关闭。成功、失败、结果未确认、未发送分别显示，各项成功条码保留。明确400等失败继续下一项；“重试失败项”不会发送已成功项。401/403停止余下请求；网络断开、超时、5xx或响应缺失条码视为结果未确认，停止余下请求并提示先核对列表。未确认项不自动重试；核对后可继续未发送项，如确认未生成，可重新勾选该记录新建批次。会话变化或组件销毁后不继续发后续请求。

父页面保留本批勾选快照，列表刷新不改变执行中的队列；批次结束刷新列表并清空主表旧勾选。“查看生成结果”可重新打开最后一批结果，不发送新请求。后续批量改造通过39项生成/打印/初始化回归及Vue类型检查；浏览器验证两项请求间隔311.2ms，无产品查询或页面错误，不写真实合包/库存。
