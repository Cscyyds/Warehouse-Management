# 本地生产接口与字段核对（2026-11-26）

## 范围和结论

核对生产领料、退料、缴库三个 docKey 的前端 API 封装、列表、新建、详情、明细编辑、确认窗口、冲减预计算、操作记录，以及本地后端路由、请求模型、响应投影、搜索白名单。

本轮按用户提供的新版 24 接口清单完成 Web 前端适配。此结论包括代码核对和请求序列化回归，不代表已对新版后端完成全部真实业务写入联调。

## 新版请求字段调整

| 接口组 | 数量 | 前端处理 |
| --- | ---: | --- |
| 三单 audit | 3 | 不再发送 audit_remark；审核、驳回移除输入和原因必填校验 |
| 退料 create、items/create、items/update | 3 | 移除 return_reason 编辑入口；表单不再构造此字段；API 层剔除旧草稿残留值 |
| 三单 delete、items/delete、unaudit、warehouse/cancel-send | 12 | 移除 reason 请求参数定义及序列化；操作保留确认步骤 |
| 三种 inbound place/simple | 3 | 当前 Web src 中没有调用入口 |
| 三种原生仓库 confirm | 3 | 当前 Web src 中没有调用入口 |

上述已删除的请求字段无论旧值为文本、空字符串还是 null，均不再发送。单据 remark、明细 remark、错误响应 reason、历史只读 audit_remark/return_reason 不属于本次请求删除范围。

## 其他字段核对

| 链路 | 核对结果 |
| --- | --- |
| 列表/搜索 | items/total/page/page_size 对齐；组合查询传 search_field 数组和 search_value 对象的 JSON 文本；排序字段与后端白名单对齐 |
